# 4出力版の実装確認（2026-09-29）

利用者の自律予測に向けた指定を反映し、raw/corrを4入力4出力へ変更した新規版。
旧入力専用版は変更せず、新しい本学習・評価コマンドを用意した。本学習は未実行。

## 実装

- 未来ne, ni, phi, γを直接出力。教師γは入力と同一定義・同一TRAIN尺度。
- loss = 3場MSE + γMSE/3。field/gamma/totalを別々に記録。
- 直接γと場から再計算するγを別々に採点し、不整合も記録。
- 自律推論は初期10frame以後、予測4場＋既知条件だけを入力する。
  γを再計算で置き換えることも、未来の真値を渡すこともしない。
- 直接γはΓ_fullに平均できる。Γ_T10は3場のcross-spectrumからだけ算出。
- 3入力3出力のnone対照と、旧版の入力追加だけの比較は保持。

## 検証

新規10/10 unit tests PASS。未来ラベルと過去入力の分離、入力/出力γの尺度一致、
直接出力と再計算の区別、γ損失のpadding除外、共通3場初期予測の一致、
γ出力headへの勾配、予測γとE/Bの正しい引継ぎ、非有限値と不正な状態の拒否を確認。
実trainerの小型4出力モデルで停止・再開を検証し、最終重みとschedulerは無停止実行と一致。

実サイズGPUチェックはsource E10_B20のTRAIN frame1400–1419、各案3 optimizer step。
正解未来10frameは教師として使う。自律推論の第2ブロックには教師を使わない。

入力C=5/6には既知E/B条件2チャネルを含む。物理場としては3/4入力。
raw/corrはnoneに比べ641パラメータ増（入力576＋出力65）。
γ readoutのgradient L1はraw=0.213、corr=0.852で非ゼロ。
lossと全勾配は有限。全案で2block＝20未来frame＝300nsの自律推論を実行。
第2入力の全物理場は第1出力と有効格子上で完全一致し、既知条件も保持。
checkpoint保存/復元後の20frame予測は完全一致。

これは未学習に近いモデルの経路確認であり、予測性能・長時間安定性の証拠ではない。
実際に3step時点では直接γと場由来γに大きなずれがあり、整合性を自動的に達成したとは言えない。
このずれを別指標として正しく取得できたことが今回の技術確認である。
